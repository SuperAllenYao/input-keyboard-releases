# IKB 输入法

为 macOS 量身设计的中英双语输入法。中英自由切换、键入流畅，自带拼音学习与英文释义。

## ✨ 主要特性

- **小鹤双拼 / 全拼**双方案可选，菜单栏一键切换
- **南方 / 北方模糊音预设**：覆盖 zh/z、ch/c、sh/s、l/n、f/h、in/ing、en/eng、an/ang 等常见拼音混淆
- **左 Shift 短按切换中英文**：模式切换时浮层即时反馈
- **英文候选自带释义 + 上下文联想**：候选词附带音标与中文释义；输入完一个词后自动基于上下文联想下一个词
- **自动成对符号**：输入 `"`、`'`、`{`、`[`、`(`、`` ` ``、`<` 自动成对，光标停在中间；中文标点风格下会自动替换为 `「」`、`《》`、`｛｝`、`（）` 等中文标点
- **中文输入三件套**：
  - **智能 emoji 与数学符号**：候选窗里出现「笑」「心」「大于」「大于等于」「平方」等汉字时，对应 emoji（😄 / ❤️）或数学符号（>、≥、²）会自动出现在候选首位附近，看见词 = 顺手能上屏符号
  - **中文模式下英文专有名词置顶**：输入 `GitHub`、`YouTube` 等英文专有名词，候选 #1 自动顶到原大小写英文词，不被拼音候选挤掉
  - **中文方头括号【】**：中文标点风格下 `[` `]` 会自动替换为 `【` `】`
- **选词体验三件套**：
  - **`cmd + del` 整盘撤回未上屏拼音**：长串拼音输错，一键清空整段，无需逐字符 `delete`
  - **下方向键展开更多候选**：候选窗默认 9 项，按 `↓` 一键展开看到全部候选（候选窗顶部实时显示当前位置 / 总数）
  - **选中文本自动包围**：选中文本后输入 `"`、`(`、`[`、`「` 等成对符号，自动给选中文本两端包围（不再吞字）
- **候选窗顶部信息条**：始终显示当前输入方案（双拼 → `双` / 全拼 → `全` / 英文 → `EN`，左侧带状态圆点）、当前拼音切分（双拼按音节用 `'` 切，例 `ni'hc`）、当前候选位置 / 总数（如 `3/47`），输入状态一目了然
- **学习与联想**：
  - **三档独立学习**：字（如「莫」）/ 词（如「司导」）/ 短语（如「执行标准的发版流程」）按字数独立记录，各自顶位门槛互不干扰
  - **长拼音串语义联想**：已学过「司导」后，输入 `sidcgrlixits` 会自动联想出「司导管理系统」类完整短语，不再拼出无意义字面
  - **最近使用优先**：常用的字词位置稳定靠前，最近使用过的有效期内不会被新词挤掉
  - **完全本地**：所有学习数据本机记录，不上传任何服务器
- **在线检查更新**：菜单栏「关于 IKB → 检查更新」一键升级，无需手动下载
- **现代视觉**：候选面板与模式切换浮层适配 macOS 最新视觉风格；关于 IKB 与更新进度面板采用暗色风格，等宽字体展示版本号和已学习条目数

## 📦 安装

1. 到 [Releases](../../releases/latest) 下载最新 `IKB-x.y.z.pkg`
2. 双击安装包按提示完成安装
3. **首次安装需注销重登 macOS** —— 否则系统找不到刚装的输入法
4. 重登后前往「系统设置 → 键盘 → 输入法 → +」→ 中文（简体）→ 选择 `IKB` → 添加
5. 首次切到 IKB 时按提示授权辅助功能权限（用于响应左 Shift 切换）

## 💻 系统要求

- macOS 14 (Sonoma) 或更高
- Apple Silicon Mac（M 系列芯片）

## 🔄 升级

- **推荐**：菜单栏「关于 IKB → 检查更新」一键升级
- **手动**：到本页 [Releases](../../releases/latest) 下载新版 `IKB-x.y.z.pkg` 双击安装，按提示输入登录密码完成安装。首次安装后请注销并重新登录系统，让新版生效。

升级不会清除已有的拼音学习数据、英文学习数据和个性化设置。

> 若已打开的应用（终端 / Slack / Notes 等）出现"切到 IKB 不响应"，重启该应用即可。这是系统层面的限制。

## 🗑️ 卸载

菜单栏 IKB 图标 → 「卸载 IKB 输入法…」→ 输入管理员密码。卸载会清除应用、词典与所有学习数据。
