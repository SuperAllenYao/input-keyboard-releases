# IKB 输入法

IKB 是一款 Mac 上的中文输入法。中英文混着打很顺手，常用的字词会按你的习惯往前排。所有输入和学习都在本机完成，不联网、不上传任何内容。

> 🧪 **公测中。** 核心输入已经稳定，可以日常使用；一些细节还在改。遇到问题或有想法，欢迎到 [Issues](../../issues) 反馈。

## 几个最顺手的地方

- **同音字按句子自动选对。** 打「的 / 地 / 得」「是 / 时」「在 / 再」时，IKB 会看你前面写了什么，把最可能的那个排第一，少翻页。
- **常打的字词会自己往前排。** 你常用的字、词、短句按使用习惯排序；连词典里没有的英文（缩写、品牌名、网名）用过几次也记得住。
- **打邮箱更省事。** 输入「用户名 + `@`」就弹出常用后缀，一选补全；你常填的完整邮箱用几次后，只打用户名前缀它就排第一。

## 完整功能

### 输入与切换

- **小鹤双拼 / 全拼**双方案，菜单栏一键切换，不用另装方案或词库
- **左 Shift 短按切中英文**，切换时屏幕上有浮层即时提示
- **南方 / 北方模糊音预设**：覆盖 zh/z、ch/c、sh/s、l/n、f/h、in/ing、en/eng、an/ang 等常见混淆
- **全拼输入容错**：像「略」(lue) 这类带 ü 的拼音，按习惯拼法就能打出来
- **候选窗信息条**：顶部实时显示当前方案（双 / 全 / EN）、拼音切分和候选位置（如 `3/47`）
- **候选窗默认 9 项**，按 `↓` 或 `=` 一键展开看全部
- **`cmd + del` 整盘撤回**：长串拼音打错，一键清空整段，不用逐字符删

### 越用越懂你（学习记忆，全部在本机）

- **根据前文选同音字**：「的 / 地 / 得」「是 / 时」「到 / 导」「会 / 回」「在 / 再」按你正在写的句子自动排序
- **三档独立学习**：字、词、短语按字数分开记，各自靠前、互不干扰
- **英文生词学习**：你上屏过、词典里没有的英文词，下次打开头几个字母就能召回，中英文模式都管用
- **不会越学越错**：连续几次没被选中的字词会自动让位；一路空格带过的「顺手确认」不会被当成你刻意的选择

### 中英混输与符号

- **中文模式下英文专有名词、常用英文词自动置顶**：打 `GitHub`、`YouTube`、`push` 等，候选第一个直接是原大小写的英文词，不被拼音候选挤掉
- **英文候选带释义和联想**：候选词附音标与中文释义；打完一个词，自动按上下文联想下一个
- **自动成对符号**：输入 `"`、`'`、`{`、`[`、`(`、`` ` ``、`<` 自动补全成对、光标停中间；中文标点风格下自动换成 `「」`、`《》`、`【】`、`（）`
- **选中文本自动包围**：先选中文字再输入成对符号，自动包在两端，不会吞字

### 打邮箱

- **邮箱后缀联想**：输入「用户名 + `@`」立即弹出常用后缀（gmail.com、qq.com、163.com、outlook.com 等），选一个就补全；继续打域名开头几个字母可缩小范围
- **记住你的常用邮箱**：你常填的某个完整邮箱地址，用几次后只打用户名前缀它就排第一；词库里没有的公司 / 小众域名，上屏一次也会被记住
- 中文、英文模式都能用

### 顺手与隐私

- **长句组词更跟手**：连续长串拼音，每次按键和上屏响应都更快，长句不拖沓
- **现代视觉**：候选窗与模式切换浮层适配 macOS 最新视觉风格；关于 IKB 与更新面板采用暗色风格，等宽字体显示版本号和已学习条目数
- **完全本地**：所有输入内容和学习数据只在本机，不联网、不上传

## 📦 安装

**快速上手**：下载 pkg → 双击安装 → 注销重登一次 → 系统设置里加上 IKB → 开打。

1. 到 [Releases](../../releases/latest) 下载最新的 `IKB-x.y.z.pkg`
2. 双击安装包，按提示输入登录密码完成安装
3. **首次安装后注销并重新登录一次 macOS**（这是 macOS 加载新输入法的固定要求，只需做一次，之后升级不用重来）
4. 重登后到「系统设置 → 键盘 → 输入法 → +」→ 中文（简体）→ 选 `IKB` → 添加
5. 首次切到 IKB 时，按提示授权辅助功能权限（用于响应左 Shift 切换）

## 💻 系统要求

- macOS 14 (Sonoma) 或更高
- Apple Silicon Mac（M 系列芯片）

## 🔄 升级

- **推荐**：菜单栏「关于 IKB → 检查更新」一键升级
- **手动**：到 [Releases](../../releases/latest) 下载新版 `IKB-x.y.z.pkg`，双击安装即可

升级不会清除你已有的学习数据和个性化设置。

## ❓ 常见问题

- **为什么装完要注销重登？** 这是 macOS 加载新输入法的固定机制，不是 IKB 特有的，只需做一次。
- **升级会清掉我的学习数据吗？** 不会。覆盖安装会保留所有学习数据和设置。
- **切到 IKB 后某个 App（终端 / Slack / 备忘录）没反应？** 重启那个 App 即可，这是系统层面的限制。
- **我打的字会上传吗？** 不会。所有输入和学习都在本机完成，全程不联网。

## 🗑️ 卸载

菜单栏 IKB 图标 →「卸载 IKB 输入法…」→ 输入管理员密码。卸载会清除应用、词库与所有学习数据。
